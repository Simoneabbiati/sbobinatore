# Sbobinatore

Carica la registrazione di una lezione e ricevi la sbobinatura, divisa in paragrafi. La trascrizione è fatta da [AssemblyAI](https://www.assemblyai.com).

Un solo file, `index.html`, che gira interamente nel browser: il file audio va direttamente ad AssemblyAI con la chiave API inserita nella pagina, che resta salvata solo nel browser di chi la usa. Nessuna chiave è contenuta nel repository.
